# Incident Triage Hub｜事件分级与影响评估助手

面向高校信息中心与企业 IT 运维团队的事件分级与应急处置后端系统。系统围绕“上报人提单 → 评估师参考 AI 建议人工定级与处置 → 原上报人复测验证 → 管理员复盘归档”构建完整闭环；在未配置外部模型或模型服务不可用时，自动切换至本地规则引擎，确保核心工单流程稳定流转。

**项目状态：设计定稿，待开发实现。** 当前仓库仅包含设计规范与交付基线文档；应用代码、数据库脚本、运行配置与自动化测试均按本套文档实施交付。
